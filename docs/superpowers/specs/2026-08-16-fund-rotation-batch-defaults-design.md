# 基金轮动策略批次默认配置设计

## 目标

调整基金轮动策略批次配置页面的初始表单值：开始日期为 `2022-08-01`，结束日期为 `2026-08-01`，默认策略为“相关性聚类代表ETF”。用户仍可手动修改这些值。

## 方案

- 在 `FundRotationTab` 的公共日期状态中直接设置两个日期默认值。
- 策略目录加载后，在可用策略中优先查找 `strategy_id === "correlation_representative"`；找不到时回退到当前目录首项，保证兼容旧目录或异常目录响应。
- 策略专用参数继续从 Catalog 的 `default_config` 初始化，不在页面重复硬编码。

## 验证

- 页面测试验证日期输入的默认值。
- 页面测试验证目录包含相关性代表策略时，首个变体选中该策略。
- 运行基金轮动相关 Vitest 测试和前端生产构建。

## 范围

仅修改基金轮动批次配置页面及其测试，不改后端请求契约、策略 Catalog 或其他页面的日期默认值。
