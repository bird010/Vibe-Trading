# 基金轮动聚类区间图设计

## 目标

在基金轮动单次回测详情中增加“聚类区间” tab。以每次基金重新聚类日期为边界，将组合收益曲线和各基金收盘价波动叠加在同一张图中；每只基金的价格在每个区间首个有效收盘价处归一化为 1，并在基金曲线上显示 B/S 标记。

## 基本事实与约束

- 单次回测已有 equity.csv 收益曲线、按基金的 OHLCV/信号/交易接口、候选池重聚类接口。
- 候选池重聚类日期是区间边界；区间起点为该日期，区间终点为下一重聚类日期前一天，最后一个区间延续到回测结束日。
- 组合收益与基金价格必须在各自区间内归一化，避免不同价格量纲干扰比较。
- B/S 颜色和浅色规则必须复用 K 线证据现有语义：正常买卖可 muted，拒绝/部分成交/延迟等状态优先级不变。
- 不修改后台回测产物、API 协议或交易计算。

## 设计

### 数据流

聚类区间 tab 激活 → 加载候选池重聚类日期 → 加载详情中的全部基金图表 → 以区间边界切片 equity/OHLCV/trades → 生成归一化 series 和 marker → ECharts 渲染。

新增前端状态只负责按需加载；默认基金集合取区间内有 OHLCV、信号或交易记录的基金，图例允许隐藏单条基金曲线。收益曲线始终展示。

### 图表

- 一个 ECharts 图，横轴为日期、纵轴为归一化值。
- 组合收益为粗线；基金收盘价为细线。
- 重聚类日期用竖线分隔，并以低透明度背景区分区间；tooltip 显示日期、区间和各可见 series 值。
- B/S marker 仅落在对应基金的收盘价 series 上；颜色逻辑与 K 线证据保持一致，muted 使用同色低透明度版本。
- 区间没有有效收盘价时不生成该基金在该区间的 series；没有任何可用数据时显示中文空态。

### 组件边界

- ClusterIntervalChart：纯数据适配和图表渲染，输入 equity、候选池、instrument charts，输出单图。
- BacktestDetailPanel：增加 tab、按需触发 loadCandidatePool/loadCharts，不承载归一化算法。
- useBacktestDetail：复用既有缓存和加载动作，不改变其他 tab 生命周期。

### 测试与验收

- 纯数据测试验证重聚类边界切片、每区间首个有效收盘价归一化、收益归一化、无行情跳过和 marker 绑定。
- 面板测试验证 tab 出现、激活时加载候选池/图表、图表空态与已有 tab 不回归。
- 运行相关 Vitest、TypeScript/Vite build，并检查 git diff --check。

## 非目标

- 不新增后端接口或改变现有 artifact schema。
- 不替换现有 K 线证据图，不改变交易 marker 的既有状态语义。
- 不增加基金筛选、排序或多图联动等超出需求的交互。
