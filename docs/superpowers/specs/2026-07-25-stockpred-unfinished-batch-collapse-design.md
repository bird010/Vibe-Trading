# StockPred 未完成批次折叠设计

## 目标

让 StockPred 页面“未完成批次”区域中的每个批次可独立折叠，避免大量策略明细同时展开。

## 交互

- 页面首次加载时，所有未完成批次均处于折叠状态。
- 批次标题行提供“展开”/“收起”按钮，并带有相应的无障碍状态属性。
- 折叠时仅显示批次 ID、批次状态、成功/失败/排队统计，以及现有“查看并生成详情”操作。
- 展开时显示该批次内的策略报告明细；再次点击可收起。
- 每个批次的展开状态独立，且只保存在当前页面组件内；刷新页面后恢复默认折叠。

## 实现范围

- 仅修改 `frontend/src/pages/StockPred.tsx` 与其页面测试。
- 使用 `Set<string>` 保存展开的 batch ID，按批次 ID 切换状态。
- 不修改后端 API、批次状态、详情物化或现有“查看并生成详情”行为。

## 验证

- 默认不渲染未完成批次的策略明细。
- 点击“展开”后显示对应批次明细。
- 点击“收起”后再次隐藏明细。
- 展开一个批次不改变其它批次状态。
