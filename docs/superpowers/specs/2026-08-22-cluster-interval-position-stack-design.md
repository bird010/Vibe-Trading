# 聚类区间仓位堆叠图设计

## 目标

在基金轮动单次回测详情的“聚类区间”页面中，在现有收益/价格图下方增加仓位堆叠面积图，用 0%～100% 的完整资金视图展示当前聚类区间内各代表基金与现金的实际仓位变化，并与上方基金价格曲线双向联动高亮。

## 范围

- 仅针对当前下拉菜单选中的聚类区间。
- 只显示该区间的代表基金。
- 保留现有组合收益曲线、基金价格曲线、B/S/D 买卖标记和深浅色逻辑。
- 新增现金区域，代表未投资资金。
- 本次不增加仓位编辑、预测仓位或独立的基金筛选控件。

## 页面布局

上下放置两张共享时间轴的图：

1. 上图：现有组合收益、代表基金归一化收盘价和交易标记。
2. 下图：基金仓位与现金的 100% 堆叠面积图。

两张图共享日期范围、区间选择和缩放状态。聚类区间边界线在上下两图同步显示。

## 下方堆叠图

- Y 轴固定为 `0～1`，标签显示为 `0%～100%`。
- 每个代表基金占一个堆叠区域，区域高度为该基金该日实际仓位 `actual_weight`。
- 基金区域颜色复用上方对应基金价格曲线颜色。
- 最上层增加“现金”区域，颜色使用中性灰色或主题下的半透明灰色。
- 现金仓位按以下公式计算：

  `cash_weight = max(0, 1 - sum(representative_fund_actual_weight))`

- 如果基金仓位合计因数据误差略超过 1，则基金仓位保持原始值，现金按 0 显示；图表不将基金仓位静默归一化。
- 持仓记录之间沿用上一条实际仓位，并使用阶梯边界表达调仓后的持仓延续。
- 已完成卖出的基金从卖出后的日期起显示 0%。
- 没有可靠实际仓位数据的日期显示断点；但现金区域只在组成数据可靠时计算，避免将缺失误判为现金。

## 上下图双向高亮

以逻辑基金 ID 为联动键：

- 鼠标移入上方某基金价格曲线：
  - 上方该基金保持正常强调样式；其他基金曲线降低透明度。
  - 下方对应基金区域提高透明度/边界强调；其他区域降低透明度。
- 鼠标移入下方某基金仓位区域：执行相同的反向联动。
- 鼠标移入现金区域：只强调现金区域，上方不强调任何基金曲线；组合收益曲线保持独立显示。
- 鼠标离开两张图的联动区域：恢复所有曲线和区域的默认样式。
- 两张图使用共享的日期指示线，悬停日期保持同步。
- 图例按逻辑基金聚合；点击基金图例时，同时隐藏/显示上方价格曲线和下方仓位区域。现金作为独立图例项。

## Tooltip

下方图悬停某一天时显示：

- 日期和聚类区间；
- 所有代表基金的实际仓位；
- 现金仓位；
- 合计仓位，正常数据应为 100%。

上方图沿用现有价格、组合收益和交易标记提示。上下图共用日期指示线，但各图 tooltip 只展示自身指标，避免内容过长。

## 数据处理

- 仅使用当前选中区间的代表基金集合。
- 通过基金行情数据中的持仓记录按日期构造实际仓位序列。
- 日期轴使用上下图可用日期的并集，仓位序列按日期对齐。
- 候选基金在当前区间没有有效行情或仓位数据时，不创建价格/仓位图层，并在现有错误提示机制中保留加载失败信息。
- 区间选择变化时，价格图和堆叠图一起重建，避免上一段区间的基金或仓位残留。

## 测试验收

- 模型测试验证：代表基金仓位正确映射、现金补足到 100%、卖出后归零、缺失数据不伪造为 0。
- 组件测试验证：选中区间只包含该区间代表基金，现金图层存在，价格/仓位图层使用同一基金颜色。
- 交互测试验证：上图基金高亮会触发下图对应区域高亮，下图区域高亮会触发上图对应曲线高亮，现金高亮不会误高亮基金。
